Making a new store's kit

Window sticker · paper stands · Totem

Have on hand (per store)

  • One round FavCircles window sticker
  • Avery 22805 square labels (1½ in)
  • Card stock + Letter paper for the stands
  • iPhone with FavCircles (super-user)
  • Totem: PLA (~100 g ring and base, ~37 g heart)
  • Totem: Posca PC-3M paint pen, super glue, 4 bumpers
  • Totem: two 1 cm pieces of 1.75 mm filament (dowels)
  • Totem: one 38 mm NTAG213 NFC sticker
  • Totem: Avery 8293 round labels (1½ in), clear tape
Start here. The window sticker and the paper stands are enough to run a store.

1Get the store ready · app, 2 min

  • Open the store's page → ••• → Store Admin. If it isn't a FavCircles store yet, this creates it (no owner, so they can still claim it).
  • Its window code and register code are shown there.

2Make the window sticker · 5 min

  • The round window sticker comes with the app-download QR code. The store's own window code goes on top of it.
  • Settings → Sticker Venues → QR button → Window stickers for several stores: tick the stores, Print, enter the first unused sticker # → one per store.
  • Print on Avery 22805 at Actual size (test on plain paper first). Each store's name prints under its code.
  • Stick the store's code squarely over the app-download code so none of the old code shows.

3Print the paper stands · app, 5 min

  • Store Admin → window code → Share → Print a sign or tent…
  • Table tents (on card stock), Counter card, and a Sign if they want one on paper.
  • Register card: the same way from the register code.

4Check it · 1 min

  • Scan the window sticker with the iPhone camera: it opens the store, not the app download page.
  • Scan a table tent: same store.
  • Pack the window sticker, stands and a few spare stickers. The store can run on these.
Then the Totem. Print it, put it together, and add the NFC tag and the store's QR label on top.

53D print the Totem · ~4 h, hands-off

  • Open the two files in Marketing/mascot/totem-print/bambu/ in Bambu Studio and print them: Totem 1 (ring + base), then Totem 2 (heart) in the heart color. Same files for every store.

6Put it together · 10 min + glue time

  • Paint the engraved heart design and JOIN FAVCIRCLES with the Posca pen, wipe with a damp paper towel, let dry.
  • Dowels into the holes, glue, press the heart halves together.
  • Glue the heart's stem into the ring, the ring into the base's slot; four bumpers underneath.

7Add the NFC tag · app, 1 min

  • Store Admin → NFC stickers → + → Points (older app: "Register"), name it Totem.
  • Hold the top of the iPhone flat on the NFC sticker until it says it's written. Tap it once to test: it opens the store.
  • Turn the base over and stick the tag to the ceiling of the round pocket underneath, right under the label recess.

8Add the store's QR label on top · 5 min

  • Settings → Sticker Venues → QR button → Totem QR labels for several stores: tick the stores, Print, enter the first unused label # → one per store.
  • Print on Avery 8293 at Actual size. It opens the same link as the tag.
  • Cover it with clear tape and put it in the round recess on the base, over the tag: one circle to tap or scan.
  • Tap it and scan it: same store both ways. Then lock the tag (NFC stickers → its row → Lock; permanent).
