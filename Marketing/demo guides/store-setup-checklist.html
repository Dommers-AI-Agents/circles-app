Making a new store's kit

Totem · NFC tag · QR label · window sticker · signs

Have on hand (per store)

  • PLA for the ring and base (~100 g)
  • PLA for the heart (~37 g)
  • One 38 mm NTAG213 NFC sticker
  • Avery 8293 round labels (1½ in)
  • Clear tape or laminate for the label
  • Super glue, 4 rubber bumpers
  • Two 1 cm pieces of 1.75 mm filament (dowels)
  • Posca PC-3M paint pen (white or black)
  • Card stock + Letter paper for signs
  • One round FavCircles window sticker
  • Avery 22805 square labels (1½ in)
  • iPhone with FavCircles (super-user)

1Get the store ready · app, 2 min

  • Open the store's page → ••• → Store Admin. If it isn't a FavCircles store yet, this creates it (no owner, so they can still claim it).
  • Note its window code (shown on Store Admin). You need it for the QR label.

23D print the Totem · ~4 h of printing

  • Files: Marketing/mascot/totem-print/bambu/. Same files for every store.
  • Totem 1 (ring + base, 2 h 45 m): open in Bambu Studio → Print → pick the ring/base color slot.
  • Clear the plate, then Totem 2 (heart halves, 1 h 10 m) in the heart color.
  • Tip: Send both files to the printer first, then start each from Bambu Handy when the plate is clear.

3Write the NFC tag · app, 1 min

  • Store Admin → NFC stickers → + → Points (older app: "Register"), name it Totem.
  • Hold the top of the iPhone flat on the NFC sticker until it says it's written. The sticker goes in the base, under the QR label.
  • Tap it once to test: it should open the store.
  • Lock it (tap its row → Lock) only once the Totem is finished. Locking is permanent.

4Make the QR label · 5 min

  • The label must open the same link as the tag: api.favcircles.com/s/<window code>?t=totem.
  • Settings → Sticker Venues → QR button → Totem QR labels for several stores: tick the stores, Print, enter the first unused label # → one label per store.
  • Print on Avery 8293 at Actual size (test on plain paper first). Each store's name prints under its label.
  • Scan one with the iPhone camera, then cover it with clear tape or laminate.

5Make the window sticker · 5 min

  • The round window sticker comes with the app-download QR code. The store's own window code goes on top of it.
  • Settings → Sticker Venues → QR button → Window stickers for several stores: tick the stores, Print, enter the first unused sticker # → one per store.
  • Print on Avery 22805 at Actual size (test on plain paper first). Each store's name prints under its code.
  • Stick the store's code squarely over the app-download code so none of the old code shows. Scan it with the iPhone camera: it should open the store.

6Assemble · 10 min + glue time

  • Paint the engraved heart design and JOIN FAVCIRCLES with the Posca pen, wipe the surface with a damp paper towel, let dry.
  • Turn the base over and stick the NFC tag to the ceiling of the round pocket underneath (right under the label recess).
  • Push the two filament dowels into the holes, glue, and press the heart halves together.
  • Glue the heart's stem into the socket at the bottom of the ring.
  • Glue the ring into the base's slot; add the four bumpers underneath.
  • Put the QR label in the round recess on the base, over the tag: one circle to tap or scan.

7Print the paper signs · app, 5 min

  • Store Admin → window code → Share → Print a sign or tent…
  • Sign for the window, Table tents (on card stock), Counter card; register code the same way for the register card.
  • Optional extra NFC stickers for tables: NFC stickers → + → Window, one per table.

8Final check before it leaves · 2 min

  • Tap the Totem's QR label: the store's card opens and the tap shows on NFC stickers.
  • Scan the same label with the camera: same store.
  • Scan the window sticker: same store, not the app download page.
  • Lock the Totem's NFC sticker. Pack the Totem, window sticker, signs, tents and spare labels.
